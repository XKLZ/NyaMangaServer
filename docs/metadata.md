# 元数据、人工编辑与持久任务

本页描述现行metadata／provider服务及仓储约束。请求类型和字段限制以[OpenAPI](../api/openapi.yaml)、internal/model及源码为准；界面入口和范围见[导航](navigation-consolidation.md)与[当前书库](current-library-context.md)。

## 来源、人工值与有效资料

来源原文、规范化字段、关联、人工覆盖和有效投影分别拥有写入规则。EH／EX共享ehentai＋gallery ID来源身份，但URL、站点及匹配依据分别保留，不按画廊ID或SHA1合并Edition。

人工编辑区分不修改、填写、明确清空和恢复继承；fields仅携带要修改的字段。空字符串不能冒充标题清空，人工标签整列表覆盖，译文独立。现行多语言是有序数组；旧单语言输入与多语言不能混用或截断已有多值，结构化属性和联想详见[属性契约](properties-tag-suggestions.md)。

有效标题遵循人工覆盖、已采纳来源、文件名回退；原文标题独立。共享来源刷新更新关联投影并保留各Edition人工值，详情与revision在同一读快照返回。提交远端结果核对任务代次、资源拥有者、内容版本及来源选择版本，再结合最新人工覆盖计算有效值。

文件变化不丢弃人工值，而是使原匹配待复核；保存冲突保留草稿，必须明确核对当前版本。SSE、轮询和后台读取不自动提升提交revision。

## 联网识别、查询与采纳

普通扫描离线。单本／批量元数据获取、连接测试、译库更新及完整导入联网步骤均由明确操作启动，不新增定时联网。

元数据识别按显式／已保存人工网址、有效webinfo.txt、本地SHA1缓存、远端SHA1搜索执行。无效webinfo可继续后续识别，有效直接网址失败不偷偷改走SHA1。只读取有界选定条目，不解压整本；未匹配、多候选、认证限制和网络失败分别记录，不能当作正常资料发布。

独立元数据获取与导入候选审核有不同采纳语义：独立任务按既有规则成功即采纳；导入来源比较／标题查询只产生持久结果，选用只暂存候选，仍需批次原人工门禁。候选分页、幂等请求、冻结输入、失败条目和未知续页状态见[来源查询](import-source-search.md)及[界面契约](import-source-search-ui.md)。不预选多候选，也不把unknown解释为已查完。

联网封面使用有界同源代理及冻结结果版本，不把远端URL直接当作宿主文件路径。来源比较仅在已授权的当前页加载候选封面，不预取私人封面或后续页；本地封面与来源原文仍分别管理。

## 提供方边界与秘密

固定支持的画廊主机／HTTPS路径、响应体、期限和重定向有明确限制。直连不继承shell代理；解析并校验目标地址，拒绝私网／环回，拨号到已校验地址，TLS验证原主机。显式代理仍受主机／路径／跳转约束，但不能把代理端解析称为本机已验证目标IP。

同站点串行限速；超时和可重试错误有界重试，认证／验证码／封禁或长时间限速暂停任务，不持续轰炸上游。Cookie只发送到对应检索站点，不发送给公共元数据或译库下载服务。秘密设置与写入版本见[安全约定](security.md)，不能写入任务、来源原文、通知或日志。

## 译库与标签联想

用户明确更新后冻结具体发行版，校验有界下载及摘要，完整词库按内容摘要原子存储，与封面LRU分离。新代次在完整解析、索引和校验后激活，失败保留旧版；当前／上一有效／正在构建代次受保护，不手工删表或当前活动文件。

完整词库成员与业务标签分开；已有标签的有效译文／频次和完整词库派生索引均由服务维护，不为所有远端词条建立业务标签。人工译文优先，缺失回退原始名；有无译文不决定词条是否属于词库。联想使用有界SQL分页及版本快照，不靠联网补齐本地读取失败。

译库来源为[EhTagTranslation/Database](https://github.com/EhTagTranslation/Database)，其[许可](https://github.com/EhTagTranslation/Database/blob/master/LICENSE.md)和[使用说明](https://github.com/EhTagTranslation/Database/wiki/开发指南)仍需单独遵循。本仓库不打包第三方译库，不自动代用户向上游发送消息。

## 任务、恢复与事件

任务有持久ID、成员、检查点和错误；completed表示处理完成，不代表所有成员成功。暂停／取消失效旧代次并传播到IO，恢复等待旧IO收尾；重试是保留父关联的新任务。用户暂停或取消不在启动时自动继续，断电／停止造成的运行中断按检查点恢复。

同书资源、同库扫描和译库更新各自互斥，扫描与元数据可按资源边界并行。结果、进度、检查点和资源事件事务化；旧工作器不能发布或清理新代次句柄。导入批次保留子任务关联、历史失败和显式跳过，不能把失败当作零建议，详见[导入流程](import-workflow.md)。

SSE需会话认证，仅传事件／资源身份与版本，业务状态重新查询JSON。重放游标、断档重同步、心跳、慢客户端期限、并发流限制和会话撤销分别处理；SSE不沿用普通请求期限。网页有限退避重连并保留JSON轮询降级，不因通知自动启动联网、替换草稿或采纳候选。
