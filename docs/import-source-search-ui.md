## 实施约定

父页面保留同阶段组件身份，只由服务器阶段决定切换。子页保留成员／方案的自身更新，不再重复查询批次。刷新仍使用保留内容的GET钩子，不清空列表、不覆盖网址／编辑草稿及冻结的审核版本。扫描失败就地显示并保留既有任务操作。

比较抽屉使用批量成员摘要match_count／source_search_id，不逐卡查询。打开单条后才读取本地详情、查询状态和该页候选；候选详情使用本地保存的规范字段与分组译名。两个标题与文件名只做共同文本高亮，不称置信度。仅ready可选用；结果与查询版本冻结，409保留选择并要求明确核对。新查询替代旧查询后，旧结果仍可比较，但需重新查询才能选用。

每页10项，查询更多时未满页继续当前页，满页加载下一页；无新结果不切到空页。未知范围与已查完、还有结果、200项／资料上限分别显示；不把已加载数当作站点总数。查询、页码、手动选择和区域浏览位置存入当前标签页sessionStorage，关闭不默认取消任务。查询请求不随输入自动发出，失败保留旧结果并显示原查询词。后续页、部分失败与重新核对均复用现有查询API。

远端封面对比复用现有同源PNG路径、候选版本和临时资源释放，只有悬停／聚焦／点击时读取，不批量预取。图片失败不妨碍文字核对。粘贴网址仍走原重新匹配流程，剪贴板失败回到原卡片的手工输入，不提前写正式来源。

选用成功关闭抽屉、回到原卡片并刷新待审核候选；不自动勾选旧多结果，不升级已冻结的旧提交，保留用户排除和网址草稿。用户随后继续原确认匹配。任务中心增加“来源查询”中文类型与筛选；查询任务的专用恢复／重试留在比较抽屉，避免走普通元数据的逐成员重试入口。
