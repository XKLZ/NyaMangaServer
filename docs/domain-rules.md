# 领域规则与数据不变量

## 导入关卡

新增／内容变化的Edition进入固定批次，普通扫描不联网。元数据先候选后采纳；版本逐Edition确认后，按真实Work去重进入系列关卡。每关所有目标必须明确处置，不要求获取或推荐全部成功。取消不删除已采纳结果。详见[导入约定](import-workflow.md)。

本文说明现行领域规则，未实现的阅读等能力单独标注；实际能力与版本见[README](../README.md)。存储与字段所有权见[数据架构](backend-data-architecture.md)，查询约定见[搜索](search.md)。

## 1. 书库、文件与书籍

一个源 ZIP／CBZ 对应一个File及其严格一对一的Edition管理身份。Edition必属一个非空Work，Series按Work组织。业务 ID 独立于文件路径、文件名与 SHA1。保存书库 ID 与根目录内相对路径，根目录可由部署配置重新映射。

代表图 SHA1 用于外部元数据查找，不证明整本文件相同，不设唯一书籍约束。文件大小和修改时间用于增量判断，需要核验时再读取内容指纹。

归档条目按确定的自然页序读取，兼容大小写扩展名，忽略目录及非图片条目。中文／日文名称和嵌套目录的编码与排序必须有匿名样本覆盖，并保持确定性。

源漫画只读，不复制到应用内部，不自动改名或删除。缺失／损坏保留记录。挂载不可用或扫描未完整枚举时不得把未见文件统统标记缺失。

外部移动／改名首版不自动识别：旧记录显示缺失，新路径可新建记录；人工重新关联需验证指纹并保留书籍 ID。不能仅凭文件名或代表 SHA1 合并。

重扫保留人工组织、收藏、人工元数据和阅读状态。内容变化后重新校验外部元数据匹配，保留覆盖值及关系并提示审查。页数变化后的无效进度需要明确调整提示。

文件索引、来源字段、人工覆盖和查询投影各有明确所有者。文件名标题是回退值，不与外部／人工标题混用；扫描不写来源、组织或用户状态。源文件离线时保留元数据和匹配当前版本的已有封面，阅读报告源不可用；当前已实现离线封面回退；在线内容变化仍拒绝旧图。

## 2. 元数据与标签

外部来源原始响应、规范化字段、书籍来源关联与人工覆盖分别保存。人工覆盖优先；清除某字段的人工覆盖才恢复使用外部值。空值与主动清空的语义在 API 中明确。

提供方以 provider＋external_id 识别元数据。代表 SHA1 可关联同一外部结果，但不同物理书籍不能自动合并。

获取顺序为手填画廊网址、有效 webinfo.txt 网址、本地 SHA1 缓存、远端 SHA1 搜索。webinfo.txt 缺失／无效时继续后续步骤；有效直接网址失败遵循原任务重试／暂停规则，不改走 hash 搜索。

有效网址仅允许受支持的 HTTPS 画廊地址；限制重定向和网络目标。原始响应限制大小并按提供方版本转换，避免将远端错误页写入正常元数据。

标签保存 namespace 与原始名称，翻译独立。标签关系物化用于搜索，不把整套远端翻译库无条件写入业务库。人工修改标签必须在事务内同步索引。

已采纳的来源原文、规范化字段与匹配依据属于持久业务数据，不按普通查找缓存 TTL 删除。原文有大小上限并排除认证秘密；来源选择、人工覆盖与有效查询投影在同一事务更新。人工翻译与机器翻译保留来源，清缓存不能清除人工翻译。

## 3. 作品、版本与系列

Work表示同一内容的作品身份，Edition表示单个File的管理外壳；同内容或极为相似内容的语言、彩色、修订等版本可归入同一Work。合集与其中单篇通常是不同Work，不能仅因部分内容重叠合并。推荐只提供待确认建议，组织关系由用户明确采纳，不自动关联。

Work含1–100个同书库Edition且恰有一个自身成员作为首选版本；Series最多1000个同书库Work，一个Work最多属于一个Series。Work名称可填写或恢复继承首选版本标题，其他资料不合并为统一来源。版本标签逐Edition有序保存，移归和拆分后保留。

- Edition移归同书库其他Work，可以跨Series；明确展示目标Series继承变化。源Work仍有版本时保留Series位置，移空才移除源Work及其位置。
- 拆分必须选择真子集，默认新Work不继承Series；明确勾选可紧接原Work排列。移走首选版本且源Work非空时必须明确指定剩余首选。
- 合并指定目标Work，保留目标ID、名称设置与首选版本。同Series取最早受影响位置，其他相对顺序不变；目标未属Series时可继承唯一来源Series。涉及不同Series拒绝合并，先处理归属。
- 拆为独立作品时，原首选Edition继续使用原Work身份，其他版本获得各自Work；默认不继承Series。
- 2→1保留Work，不再退化解散。删除Series只解除关系；不删除Work、Edition或File。
- 回收站保留关系；永久清除最后一个Edition才清理空Work和Series位置，源漫画始终只读。
- Series成员增删、移动和完整有序替换以Work为单位。标题自然排序只在明确点击时执行，另校验目录查询版本。HTTP移动位置0基，界面位置1基。

预览与提交共用同一领域变换；确认重放预览返回的规范命令，保留生成ID、空数组和冻结revision。目标与版本变化时显式重新核对，不静默提升草稿版本。原版本组和旧组织接口返回410，旧books只作HTTP兼容适配。

收藏/隐藏、来源、人工覆盖、属性、封面和版本标签均归属Edition。普通收藏不改变资料编辑revision；“收藏全部版本”是明确动作，事务校验各成员状态版本。隐藏或回收首选版本时，查询选择符合筛选条件的稳定替代代表，不改写首选设置。

## 4. 搜索

先匹配Edition元数据、标签、属性、用户状态及Work有效名称，再按Series或Work折叠。普通搜索词也匹配Work名称；title:与title_original:仅限定Edition字段。保留匹配成员信息；次版本命中不能丢失。

用户隐藏控制可见性，分组折叠不是用户隐藏。隐藏范围明确显示用户隐藏的逻辑条目；文件状态筛选可查到缺失／损坏记录。

先确定匹配的逻辑结果，再排序、计数和分页。计数与页内结果采用一致快照。稳定排序必须追加稳定 ID；不能先对物理书籍分页再折叠。

标题包含、标签包含／排除、命名空间、引号短语、前缀和 AND／OR 通过统一解析器构成语法树。使用参数化 SQL，不直接执行用户表达式。非法语法返回定位错误。中文短词应有实际子串匹配能力，不能只依赖英文分词。正则和向量查询不在首版。

## 5. 阅读

进度按物理书籍和账号记录；不同版本不共享页码。当前页、实际页数、完成时间、阅读次数及最后打开时间分别建模，updated_at 不代表最近阅读。

允许回读和重置。进度更新携带记录版本，并发冲突返回当前状态，由客户端明确处理，不能用最大页码直接吞掉回退操作。

页面接口只解析已登记书籍与页序号。复用有限归档会话，限制句柄、解压并发与缓存；请求一页不解压整本。图片和封面要求认证，支持内容版本校验与浏览器缓存。

## 6. 任务与维护

任务成员是固定 ID 快照；总数不随并发扫描改变。任务状态保存在数据库，SSE 只是通知。远端认证错误暂停，单本无结果或坏文件可单独暂缓。

所有副作用按可重复执行设计，检查点与结果写入需保持一致。取消传播到下层；即时重启使用代次校验，旧结果不能覆盖新任务或清除新任务句柄。

健康检查与修复分开，修复和迁移前备份。常规启动只恢复明确可恢复的任务，不静默删除组织数据。当前私有整实例备份含凭据及已有可重建缓存，不含源漫画、模型、程序或旧备份包；不与历史脱敏导出设想混用。

活动任务及成员不得按历史清理策略删除；终态明细、临时文件和升级快照分别定义保留窗口／配额。临时清理须排除活动拥有者，升级清理不得删除唯一有效回退点；具体数值与清理入口随功能实施，不由本轮文档触发删除。

## 7. 素材、派生数据与事务边界

人工封面、标签图片和必须保留的导入附件属于长期素材，数据库登记素材 ID、相对键和摘要，随业务备份；不能混入自动封面 LRU。文件先原子落盘再提交引用，失败残留在核对引用后清理，共享文件不能因单个引用解除而删除。

自动封面与页面派生图使用独立预算，键包含书籍、内容版本、选图／页身份和处理规格版本。缓存写入失败允许业务索引降级提交并记录错误；数据库错误仍整体回滚。清理图片缓存不能删除元数据、人工素材或独立向量索引。

本地推荐特征采用独立可重建索引；面向用户的向量检索仍未交付。索引需记录输入指纹、模型／预处理版本、维度与 generation，不跨模型空间比较；重建校验后切换活动代次。跨库结果回主库验证实体与输入版本，陈旧结果不能展示为有效；向量损坏不阻断普通业务。推荐模型与预处理按正式清单固定，后续检索引擎另行设计，不依赖Apple Vision。

认证摘要和会话位于主库。私有升级快照及当前整实例包完整保存认证资料，站点凭据及密钥也须配对保留；不靠排除secrets目录冒充脱敏。整实例恢复使用备份账号密码重新登录，所有旧会话失效，不要求重置密码。

## 8. TreeC 兼容约束

保留源书籍 ID、组织关系和人工信息的映射。TreeC 原始字段没有区分人工值和外部镜像时，保守保留现有有效值，不能假装已准确推断来源。

未来新数据模型改变旧状态语义时，必须保存原值并在迁移报告说明。未支持的专题、偏好、任务历史和推荐信息保存在附件，不直接执行。详见 [迁移兼容性](migration-compatibility.md)。

历史基础重构曾获准重新建库；当前增量升级禁止清库，也不意味着TreeC数据可丢弃。正式使用后的数据库仍以版本化迁移演进；此前基础重构的重置按明确授权执行；后续增量不再次清库，保留已有账号和数据。

## 来源任务的并发与持久规则

来源提交同时检查内容版本与选择版本，投影采用最新人工覆盖；EH／EX 共享 gallery ID 身份。空值／继承／填写独立，标签整列表覆盖。单本未匹配或多候选不会中断其他成员；有效直接网址失败不改走 SHA1。

扫描与元数据可并行，同书元数据资源互斥。暂停／取消立即失效代次，恢复等待旧 IO；重试有父任务，扫描子集不做全库缺失判断。结果、进度、检查点和通知同事务。认证限制或超过一分钟 Retry-After 暂停；用户明确恢复。

人工译文优先于按具体发行版物化的译库；切换失败保留旧版，未使用远端词条不进入本地标签表。SSE 仅通知资源 ID／版本，不作为业务状态或传送秘密的渠道。

## 管理维护补充

- 停用、回收站、个人隐藏互相独立；恢复书库不恢复此前单独移除的书籍，重新启用不自动恢复任务。
- 源漫画只读；移除/永久清除针对应用索引，保留扫描排除，重新纳入须明确动作。组织清理复用同一事务变换，预览也校验容量。
- 人工封面归长期素材，封面选择版本独立，元数据代表SHA1不随封面修改。
- 手动来源预览须确认，解绑不清人工覆盖，不删除其他书籍仍引用的来源。
- 维护先预览、后校验版本执行，资源旧代次失效并等待IO收尾；重复执行计划不能重复发布副作用。
- 网页管理用检视与完整阅读分开；普通API保留客户端使用，管理查询显式处理回收站/停用状态。

## 页面目录与摘要补充（2026-10-16）

页序是只读归档解释规则，没有源文件编辑或人工页序功能；目录按需缓存并有资源上限。查找SHA1采用`content-page8-v1`，封面选择独立，算法变化不冒充源内容变化。版本成员支持多个有序人工标签，旧单值不能截断多值。细节与兼容错误见[专项约定](archive-manifest.md)。


## 同作品发现方案

发现只推荐singleton组成Work，或singleton加入已有multi Work；不会自动拆合既有multi。组成要求成员两两达标，连通关系不能链式扩组；加入使用最佳支持版本，同时检查全部目标成员的明确冲突。真实成员数包括回收成员，隐藏不改变Work类型。完整方案的语义键、组织CAS、成员排除resolve与相关输入指纹共同保护采纳；来源、标签、用户状态和文件不随整理合并。

忽略是完整方案决策，不能推导每条配对都负例。009后新采纳拥有组织撤销快照，revision只增长，撤销不覆盖普通资料和无关系列。完整流程和证据见[全库发现](work-discovery.md)。


## 导入推荐失败与明确跳过

版本或系列查找失败不得等价于“未发现建议”。最新持久预留尝试决定本阶段状态；旧失败保留在历史中，成功重试后不继续阻挡。明确跳过绑定该次失败任务，只返回人工归属审核，保留所有组织和已经采纳的结果；下一阶段仍须用户确认。旧完成批次不自动重开，但应展示历史失败。书库停用不影响其他书库，同书库推荐范围不扩大。


## 标签管理与原作／角色关系（2026-10-27）

parody界面称原作，和Series／Work不同。标签身份及人工译名、人工 confirmed／excluded 关系全库共享，目录与自动证据必须明确当前书库。目录仅默认列实际使用标签，统计含隐藏、缺失损坏和显式停用库的非回收Edition，按真实Work去重；其余所有命名空间归内容标签，不抛弃未知值。

排除original／origin占位后单原作证据只说明该Edition的可靠共现，不冒充人工确认。全局排除优先；角色允许多个原作。多原作的可靠候选竞争、多个剩余或书外归属矛盾保留未归类，不能按ID挑一个。唯一剩余只在本书成立，推断不回灌证据或跨书连锁。逐本自动否决不升级为全局排除；全局人工确认与局部自动否决分别展示，标签不因任何关系决定增删。

恢复自动／恢复逐本推断保留递增CAS墓碑，旧revision不能ABA重用。SSE只提示刷新，不能替换草稿版本。关系分区可以重叠，未归类不得从总数中消失。完整规则、状态码及双向分页接口见[标签管理](tag-management.md)。

## 标签个人关注

关注身份是当前认证account＋既有tag，跨书库、五类及未知namespace共享；关注与取消使用独立单调CAS墓碑，不修改标签身份、人工译名、关系、图片、Edition收藏或推荐／元数据来源输入。词库独有条目不能自动变为业务tag。已关注列表允许当前库零Work，关联漫画仍遵循原明确库范围。变更只抬升本人follow epoch，SSE在服务器按owner过滤，不向其他账号发送tagID。见[完整契约](tag-follows.md)。

## 本地画廊高亮

高亮只按正式edition_sources→external_metadata的ehentai gid读取所有启用未回收库、未回收Edition，包含隐藏。至少一条保存索引available且来源内容revision相符为已收录，其余有正式关联为记录待检查，无正式关联不标记；同gid多Work合法。未采纳URL／候选不算，不探测文件、不推断内容或版本身份，不触发组织／推荐／下载。独立连接与查询权限见[本地画廊高亮](local-gallery-highlight.md)。

## 整实例备份与恢复

整实例包以相同构建／schema账本为边界，密码、人工empty、组织／标签所有权、审核、决定与撤销逐ID保留，源漫画独立管理。目标配置保持；根只能显式映射允许键，stat不能证明内容相同，暂不关联不触发扫描或批量missing。恢复先完整校验、CAS确认、目标保全，再正常重启持锁激活；旧会话失效，原运行任务暂停，自动扫描／子任务／增强／重验保持持久静止。新业务写入后整实例回退拒绝覆盖；故障目标的离线显式替换必须独立预览、确认及保全原unsafe和健康日志。详见[备份恢复](backup-restore.md)。

## 多账号与阅读兼容规则

全局管理员与逐库viewer/editor相互独立；新账号不回退全库。浏览、搜索计数／分页、图片、标签关系、任务／方案／批次及事件由服务端按授权收窄，个人收藏／隐藏／关注／保存搜索／阅读绑定会话账号。撤权／停用暂停有关执行并失效旧generation，重新授权不自动恢复。共享规范来源的更新需要所有受影响库的编辑权，否则整次拒绝并保留候选。

阅读属于账号+Edition。显式新session计1，重连重试不计；进度可倒退，末页不自动完成，重读不取消完成。uncomplete保留进度，reset清页码及完成并保留次数／last_read_at。所有时间由服务器给出；内容变化保留旧值并stale，明确确认会重置旧页码／完成，不自动套用。远端页数／体积不覆盖File或参与推荐输入，旧未知／人工值继续受保护。详见[完整协议](data-compatibility.md)。
