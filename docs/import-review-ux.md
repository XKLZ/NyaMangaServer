## 已确认行为

- 整批未处理成功项默认选择，取消集合保留，候选版本变化不能自动重基；勾选不等于采纳。
- 推荐资料与已有人工覆盖合并参照；专用抽屉保存时完整采纳候选、人工修改、审核完成同事务。无候选人工录入并确认，不离开工作台。
- 远端封面仅在悬停约300ms、聚焦或点击展开时请求同源认证预览，使用既有代理、独立有界缓存，列表不预取，不替换本地封面。
- 保留所有阶段门禁、原子冲突、未提交草稿与离开保护；不改变推荐算法、已有审核决定或真实任务。

## 实施与证据

分批记录查询／原子审核、卡片／批量操作、封面／视觉交付。具体检查及尚未验证项随实现补充。schema13及001–013保持，本轮没有新增迁移。

### 查询与原子人工审核

已增加review-selection轻量分页查询（服务端筛选ready/pending/all），返回冻结成员／候选／Edition编辑revision。成员页批量附带本地封面身份、已有元数据标志、状态和本地标签译名，列表不读取保存的上游Raw响应；批次附同一快照内状态计数。原成员和候选接口保留兼容字段。

editor只读预览完整候选叠加既有人工覆盖；manual-review复用来源采纳、覆盖、有效元数据及属性投影，编辑／采纳／确认同事务。无候选仅保存人工资料并确认；候选更新、文件内容、来源选择、Edition和成员版本不符均拒绝，错误不产生部分保存。批量审核可附expected_edition_revision；旧客户端未附时保持原有兼容语义。

匿名60项仓储用例、HTTP/OpenAPI三关完整流程与相关元数据回归通过；定向race覆盖新查询、人工审核、回滚及HTTP全流程。测试临时文件使用项目.runtime/tests/tmp。前端新增4项纯函数测试通过，覆盖整批选择、取消保留、版本变化不自动重基、1000项上限及NFKC重复片段；尚不代表UI验收完成。

### 按需封面与并发边界

官方gdata的thumb存入可选候选字段，旧候选从已保存且有界的Raw单项响应恢复；没有地址则不可用，不重新获取整份元数据。浏览器只请求认证的candidate-cover同源入口，必须指定候选revision，拒绝额外URL参数。请求前后均校验候选版本。图片客户端仅允许HTTPS官方ehgt.org及s.exhentai.org/t/，校验DNS／重定向，复用代理配置但不发送站点Cookie；来源响应中的敏感值先脱敏再提取图片地址。

下载上限4MiB／20秒，解码前限制8192边长与800万像素，复用现有comic.Pool的并发／内存预算并生成最多320×480 PNG；返回上限2MiB。独立imagecache实例使用cache/import-previews/v1、128MiB／1000文件，复用有界LRU和无符号链接路径检查，不占本地封面额度。请求去重、取消后新读取、缓存损坏和单项失败均有边界；图片失败不阻止文字审核或采纳。

提供者、独立缓存和真实匿名HTTP测试覆盖官方目标、私网DNS拒绝、代理复用、Cookie隔离、重定向、大小限制、原始thumb恢复、鉴权、候选版本、缓存、坏图片降级、并发2和取消。没有为验证下载私人远端图片。

### 批量审核的共享来源修正

Edition起始版本先整批核对，避免本事务刷新共享来源时造成后续成员自冲突；所有同批审核指纹最后从事务最终投影生成。已有来源的两成员匿名用例验证采纳和后续放行。界面仅在确有原资料时提供保留操作；重取失败保留旧候选，并分别展示原结果网址与最新失败请求的网址。

### 2026-10-24双标题与批量审核调整

本节替代上文三标题及独立元数据放行按钮的界面约定。默认比较文件名与覆盖文件名字符最多的来源标题，同分优先原文标题；只比较这两个文本，NFKC／大小写／扩展名处理不变，不参与推荐或候选判定。两行限制与复制完整原文保留；完整来源标题移到展开资料。常驻分类／语言／评分及标题悬停浮窗移除，使用图标、较强高亮、胶囊画廊尾码和异常卡片背景。

元数据阶段恢复独立Ant Steps；选择图标靠左、筛选靠右，只在底部显示计数。正常单项确认移除，批量确认与“本次不更新所选元数据”并列。不更新仍提交skip，仅保留已有资料并完成本次审核，确认框明确不删除漫画或元数据；旧候选重取失败仍须明确核对后采纳。

### 2026-10-24卡片对齐复审

按Refactoring UI层级／分组（§2.1、§3.6）和Web Design Guidelines焦点／图标规范复审：正常已选卡片仅保留选择框与边框，不铺背景；异常背景仍保留。对比文字去掉强调底线和悬停下划线。顶部只放选择、封面、双标题与状态；正常文档流的底部工具栏统一32px按钮、16px线性图标和8px组内间距，网址／打开／粘贴成组，编辑／更多靠右。展开箭头与选择框使用同一32px列，不再绝对定位到卡片底部；完整资料插入工具栏下方，展开内容不作为滚动锚点。手机工具栏可换行，标题及长网址不会横向溢出。

图标操作补充悬停与键盘聚焦提示，标题本身不加浮窗；短码仍复制完整网址、打开仍使用完整链接。审核、草稿、选择与阶段推进语义保持，不修改API／数据库／依赖，不重启服务。专项匿名流程加入背景、无底线、列轴、展开／收起按钮位置与焦点、粘贴提示检查，配合既有跨页、人工编辑、旧候选和门禁回归。

## 2026-10-25建议中心审核：后端

版本／系列新增organization-review只读摘要及complete收尾接口。摘要同一读事务计算主建议数、当前阶段子任务、同库后台重验状态和快照指纹；指纹包含本批所有主／备选／派生方案版本、已保存及实时元数据／组织指纹。complete在同一写事务核对批次版本、阶段和指纹，仅在review且无主建议／任务／重验时为未单独审核成员记录当前归属，随后调用原阶段变换。旧版单本决定及上游指纹不覆盖，失败整体回滚；重复提交不能重复启动任务。剩余备选仅本批作废，不插入人工否定。原continue和成员计数语义保留，不新增迁移、表或依赖。

批次方案列表支持alternatives=false显示主建议，缺省true兼容旧客户端；增加作用域方案详情及系列成员读取。调整、采纳仍复用原组织接口与事务。匿名仓储覆盖无建议、采纳／不采用、重验阻挡、快照变化、上游及旧审核冲突、事务回滚、重复请求、备选作废不记否定及无关Edition归属保持；HTTP验证新收尾接口和完整三个阶段。相关测试、race、OpenAPI通过后才更新日常API，随后实施前端；本节不是前端已验收声明。

### 2026-10-25单方案工作台交付

导入页显式加载版本／系列及专用样式，不再依赖先访问全局管理页面。版本与系列阶段采用280px建议列表＋单方案审核；手机切换列表／当前建议。删除所有成员列表、成员筛选和逐本确认，未参与建议的作品保持现状。原文标题优先、复制完整标题、本地封面、嵌套漫画详情、既有标签与已有／本次加入身份保留。成员分页25项，已有组／系列默认折叠，单方案操作固定底部；成员选择、新系列名和拖动／键盘排序直接编辑。全局管理页保留原默认行为，导入模式使用可注入的批次作用域读写。

删除保留版本组、建议强弱及通用风险说明，只展示真实差异、阻塞和系列名称影响；名称读取同源且并发最多2，名称未取得时不提交有相关影响的版本建议。采纳／不采用后顺延当前列表位置，页末回到有效页。所有草稿持有原方案快照，刷新不覆盖；版本／系列409禁用提交，明确核对后保留仍有效的选择、名称及新成员顺序，已有系列成员相对顺序以当前值为准。多方案草稿可继续或明确放弃。暂停／失败批次不允许修改或提交。

最后一次明确操作才激活收尾意图，后台重验未结束时只等待并刷新；主建议重新出现则继续审核。初次进入、刷新或恢复没有自动收尾意图；无建议显示继续按钮。完成失败不重复整理，保留结果并单独重试。其他建议通过only_alternatives=true服务端先筛选、计数再分页；默认主队列不要求逐条否决备选。历史读取与撤销始终检查批次关联；已结束批次只读／撤销可用，恢复或新增采纳仍禁止。复用已有撤销事务，不自动重新打开导入。
