# v0.7.0-beta.2

第二个公开测试版，面向 Linux AMD64，schema30。新增服务端客户端协议，管理网页仍不包含完整阅读器。功能介绍见[README](../../README.md)，安装与升级见[部署说明](../../deploy/README.md)。

实际发行状态以本版本 [Release](https://github.com/XKLZ/NyaMangaServer/releases/tag/v0.7.0-beta.2) 和其对应提交的 [Actions](https://github.com/XKLZ/NyaMangaServer/actions/workflows/release.yml) 为准。只有完整检查、原生AMD64镜像及匿名标准恢复通过后才发布相同的已测镜像。

## 变化

- 设备账号密码登录、30天可续期的独立Bearer会话、设备撤销和账号／书库权限隔离。设备仅浏览与管理个人状态，即使管理员账号也不能通过设备凭证执行管理操作。
- 实例身份、缓存世代、能力发现、按作品查询和阅读上下文；原文优先标题、明确首选／搜索入口／继续阅读版本。
- 客户端页索引从0开始；内容和解析版本校验、强ETag、提前304、同页处理合并、有界图片缓存及显示优先预加载。
- 明确重新开始阅读、原子计次、完成状态保护和多设备revision冲突。
- 原文件流式下载、整文件SHA256与单段Range续传；版本化离线清单及批量变化核对。
- 离线阅读、收藏、隐藏和关注的有序重放；事务回执、幂等、依赖、事件时间及重连核权。

协议及默认限额见[客户端基础与在线阅读](../client-foundation.md)、[下载与离线](../client-offline.md)和[OpenAPI](../../api/openapi.yaml)。原文件导出不承诺远程撤回；断网设备无法即时获知撤权。

## 升级与恢复兼容

从 beta.1 的现有实例启动本镜像时，应用按正常升级路径创建必要一致性快照并应用028–030；001–027保持原账本。新结构保留原账号、资料、组织和个人状态，不主动扫描、推荐或下载内容。

升级前正常停止旧容器并保存可用备份和旧镜像。不要并行运行两个版本访问同一数据目录，也不要直接用旧程序打开升级后的数据库。

整实例恢复仍要求相同发行版本、完整构建身份和迁移账本。**beta.1备份不能直接交给beta.2恢复**；需要先用匹配的beta.1程序恢复，再正常升级。beta.2备份同样需要保留本次匹配镜像。备份包含秘密且不加密，不包含源漫画或模型。

## 验证与限制

本地复核包括匿名设备／在线图片／下载／离线操作／迁移及标准恢复定向测试。新增回归明确验证搜索快照隔离账号和实时授权版本；底层公共目录版本已包含该保护，无需重复修改业务实现。

本版发行门禁更新为当前迁移版本，并在生产程序和原生Linux AMD64镜像中增加匿名设备登录、权限拒绝、页面200／304、Range／SHA256、离线重放，以及恢复后设备失效和缓存世代变化检查。并发回归集合增加客户端图片、下载与离线场景。

CI仍执行普通Go测试、vet、前端静态／单元检查、串行选定race、生产网页匿名浏览器和标准备份恢复。每个阶段是否通过以对应工作流为准，不以定向源码测试代替镜像验证。

未验收真实客户端后台下载、移动端持久化、飞行模式交互、N5105新版本性能、ARM64发行及真实推荐模型。本次发布不升级现有NAS或Mac实例，不改动用户数据。
