# 专业管理台与阶段自查

实施基线为M4本地交付 `1c61abc`，开发分支 `codex/admin-console`。本阶段把网页定位为管理入口；漫画展示、完整阅读及进度同步由后续客户端阶段建设。本文说明已实现的操作语义，实际通过情况及限制见[验证记录](admin-console-verification.md)。

## 自查基线

| 系列 | 创建、改名、完整成员更新、显式排序、删除 | 增量成员接口、搜索分页、容量预览与提交一致 |
| 版本组 | 创建、成员增删、主版本、标签与解散 | 明确错误、便捷操作、组退化和事务回归 |

| 网页 | 业务功能已接通 | 专业导航/表格/编辑面板、草稿保护、冲突与反馈 |

源码审查发现的组织容量问题是：从满容量系列中移出或解散版本组会扩展逻辑条目；此前预览路径未执行提交后的全局约束，可能出现预览成功而提交回滚并返回500。修复必须同时检查预览与提交，不以放宽系列上限规避。其他发现包括任务列表固定取最近100项、组织闭包详情可能加载过量成员、网页静默截断选择、空名称草稿回退原名和未保存编辑保护不统一。缺陷是否已修复必须以测试记录为准。

## 管理导航

根地址跳转 `/admin/`。漫画管理以物理书籍表格为默认入口，提供搜索、书库/文件/元数据状态筛选、列设置、分页和明确物理成员的批量操作。系列和作品分别管理，不把折叠展示当作索引删除。

编辑面板展示概览、来源、人工字段/标签、封面、组织和文件诊断；URL可以定位，关闭回到原列表。缩略图、放大及单页校验用于管理确认，不提供连续阅读或虚构阅读状态。

书库、元数据处理、系列、版本组、任务、维护和设置是独立页面。桌面优先，同时支持手机完成增删成员、上移下移、任务处理和维护确认。选择超过1000本明确拒绝，不丢弃尾部选择。

字段的填写、明确清空、恢复继承分开表示。来源刷新与扫描不得覆盖人工值。通知只提示状态变化；编辑期间不会自动提升提交版本，保存冲突时保留草稿并展示当前值。

## 操作语义

### 索引、停用和回收站

源漫画始终只读。移入回收站保留书籍、元数据、人工值、个人状态和组织关系，正常列表排除，扫描不自动恢复。恢复遵循当前关系，不回滚其他合法编辑。书库恢复不恢复此前单独移除的书籍。

停用书库阻止新扫描和源IO，保留可编辑信息和已有封面，相关任务暂停。启用不自动恢复用户暂停任务或补跑周期扫描。永久清除是单独操作，先展示关系影响，按组织规则处理主版本、组退化、顺序和历史引用；它不删除源文件，保留扫描排除标记。

重新关联必须从配置允许根浏览并选择相对路径。源文件可由用户在应用之外移动；应用不提供移动/删除漫画功能。不凭代表图SHA1断定整本相同；内容替换需明确确认，保留书籍ID、人工值、用户状态和组织。

### 封面与素材

自动封面、归档页封面和人工上传封面分别管理。人工素材位于data/assets，数据库保存相对键、摘要和引用，派生图才参与缓存淘汰。更换封面不修改元数据识别SHA1。选页内容变化后需要重新确认，不静默换页；人工素材继续保留。

上传仅接受JPEG/PNG/WebP，最多10MiB，同时限制像素和解码资源并重新编码。所有封面和页面访问要求认证，返回内容的ETag根据实际字节计算。

### 来源与任务

手动URL先获取候选预览，成功也不立即替换旧来源。预览30分钟有效，重启后可继续；确认检查内容/来源选择/记录版本。解绑保留人工覆盖，只解除本书关系；清人工URL是独立动作。用户主动批量获取仍按明确成功结果自动采纳，多候选等待处理。

维护、封面重建和来源预览沿用持久任务。目标与版本固定，执行幂等，取消/暂停使旧代次失效，维护操作等待相关IO收尾。任务状态在数据库，SSE只发送资源变化通知。

### 清理

诊断分别展示缓存、素材、临时文件和升级快照。清理先预览再执行；保护引用中的素材、活动资源和必要回退快照。不默认开启定时清理。完整可导出备份/恢复尚未实施，私有升级快照不能当作脱敏业务备份。

## 日常操作指引

| 需求 | 入口与操作 |
|---|---|
| 导入漫画 | 书库与导入 → 添加书库 → 从允许根登记 → 开始扫描；任务中心查看进度和损坏成员 |
| 批量处理 | 漫画管理勾选明确物理书籍，跨页保留选择；上方执行元数据获取、组织或回收站操作，最多1000本 |
| 修订资料 | 点击标题打开编辑面板 → 字段与标签；逐字段选择继承、填写或清空后保存 |
| 替换来源 | 来源匹配 → 输入支持的画廊网址 → 获取预览 → 核对差异 → 确认采纳；单独解绑不清人工值 |
| 调整封面 | 封面面板选择归档页或上传图片；可恢复自动选择，也可启动重建任务 |
| 建立版本组 | 选择同书库成员并查看创建预览；版本组管理可加入/移出成员、改主版本及版本标签 |
| 整理系列 | 系列管理创建系列，搜索加入成员；上移/下移或明确按标题自然排序，核对预览再保存 |
| 排查异常 | 元数据处理筛选无来源/待复核；文件诊断与任务中心保留具体错误及成员状态 |
| 暂停书库 | 书库与导入停用；已有缓存和整理保留，重新启用后按需手动恢复任务 |
| 移除与恢复 | 移入回收站只隐藏应用索引；维护中心恢复，永久清除另需预览和确认；两者均不删除源漫画 |
| 文件移动后修复 | 文件诊断重新关联，从允许根浏览相对路径；无法确认相同内容时需明确确认替换 |
| 释放存储 | 维护中心查看分类用量，选择清理类别，先查看数量/空间/保护项再执行 |
| 管理联网设置 | 站点与译库设置默认站点、出口与只写凭据；连接测试及在线更新都由用户点击 |

列表筛选、页码和编辑书籍ID保存在地址栏。保存搜索保存已应用条件，重新打开从第一页查询。通知不会覆盖未保存的草稿；发生版本冲突时保留草稿，核对当前数据后重新确认。离开编辑页前会提示未保存修改。

## 开发和边界

```sh
make install
make dev
# Ctrl+C正常停止，数据保持
make check
make test
make test-race
make e2e
make admin-smoke
make search-scale
```

日常实例固定 `.runtime/dev`，匿名实例 `.runtime/tests/runs`，报告 `.runtime/tests/results`。不创建管理台阶段专属日常数据路径。

两名执行Agent分别修改后端和web，主Agent维护[接口契约](admin-console-contract.md)、集成、提交和升级。完整构建/浏览器/进程测试串行，避免共享产物与端口冲突。001/002/003 SQL校验和保持，新增迁移，禁止清库。最终开发实例升级不自动扫描、整理、清理或联网。

本阶段不运行Docker/Ubuntu/ROS/NAS，不修改相邻项目，不推送或发布；真实站点由用户网页主动验证。完整阅读、客户端、向量和TreeC转换留到独立阶段。
