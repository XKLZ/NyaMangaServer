# 书库扫描、文件与图片

本页描述现行library／comic／imagecache及仓储约束，接口以[OpenAPI](../api/openapi.yaml)为准。普通扫描与完整导入不同：扫描只离线登记文件，完整导入另有联网授权与人工门禁，见[导入流程](import-workflow.md)。

## 根目录与稳定身份

书库通过配置root_key引用允许根，保存相对路径，源ZIP／CBZ始终只读。应用数据目录不得与书库嵌套；源访问通过受限根解析，拒绝越界路径与符号链接，不从邻近项目或生产库取默认输入。

File与Edition严格一对一，每个Edition属于一个非空Work；身份独立于文件名及SHA1。扫描使用书库和相对路径定位已有记录，更新文件／索引信息，保留人工元数据、来源、组织、标签和账号状态。外部移动或改名不凭摘要自动合并；重新关联走显式维护预览和身份核验。

源文件大小／mtime变化推进content_revision，旧版本图片请求被拒绝，匹配资料进入待核对状态，人工值及关系保留。坏文件、局部坏图和缺源分别记录，不自动删除索引或源漫画。

## 扫描与取消恢复

同一书库最多一个非终态扫描，文件处理并发有界。周期扫描默认关闭；启用后仍离线，目录故障推迟下一次尝试，不积压重复任务。停用、回收、目录身份异常沿用维护限制。

完整枚举后冻结成员；每项结果、统计和检查点事务提交。取消立即使generation失效并传播到排队与IO，旧工作器不可发布，新任务等待旧IO收尾。重启仅恢复可恢复的中断任务，已取消任务不恢复；暂停类任务的用户意图不能被启动流程覆盖。

结束前重新核对目录身份和枚举结果。挂载故障、枚举未完成、目录变化、取消或可疑空库均不授权批量missing；子集重试不进行全库缺失判断。缺失更新与成功结束事务化，避免留下半批状态。

## 页序、摘要与资源边界

ZIP条目拒绝绝对路径、路径穿越、反斜杠、NUL、盘符及符号链接。UTF-8和显式旧编码的解释必须确定，不用替换字符掩盖解码失败。自然页序按完整名称、规范化文本、数字串及稳定原序号确定，同名条目仍有独立身份，不解压整本到磁盘。

封面默认第一页；查找摘要使用content-page8-v1：至少8页时取第8页，否则第一页。摘要是查找信号，不是唯一文件身份，人工选封面不改查找摘要。目录是按需、有界的归档会话缓存，不持久化逐页业务表，细节见[目录与摘要](archive-manifest.md)。

当前归档中央目录上限10000条／16MiB，单页64MiB、图片100MP、声明图片总量8GiB；目录缓存32MiB，最多八个归档会话；图片处理并发2、估算解码内存预算256MiB。读取还核验实际解压量、CRC和尺寸，不只信任ZIP头。JPEG、PNG、静态WebP、GIF首帧及BMP按现有处理链支持；不把有界图片接口当作已交付完整阅读器。

## 封面、素材与管理查询

自动封面在data/cache/covers/v1分片存储，有容量／文件数和LRU限制；写入失败允许有边界的降级。源离线时可返回仍匹配当前身份的既有封面，在线源内容变化不得返回旧图。认证先于条件缓存，图片接口使用内容／封面版本与ETag保护。

人工封面属于长期素材，不进入自动封面LRU。素材ID、相对键和摘要归服务管理，不接受客户端任意文件路径。清理、重新关联、回收和永久清除需要原有预览、版本及真实影响确认，源文件不随应用索引操作删除。

漫画管理当前书库、停用库显式进入、详情和分页规则见[当前书库](current-library-context.md)；搜索／折叠语义见[搜索](search.md)。匿名验证使用独立生成样本，不把manual或真实书库作为默认测试集。
