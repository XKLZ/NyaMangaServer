# 搜索、账号状态与保存条件

本页描述现行search／userstate和仓储投影规则，接口以[OpenAPI](../api/openapi.yaml)为准。组织关系以[Work／Edition模型](work-edition-model.md)和[领域规则](domain-rules.md)为准，不再使用旧逻辑条目／版本组退化模型。

## 查询语言与范围

支持普通词、title:、title_original:、命名空间标签、末尾星号前缀、引号、括号、减号排除、隐式AND及显式AND／OR，AND优先于OR。普通词匹配有效显示标题、原文标题及Work有效名称，字段限定词仅匹配对应Edition字段；输入经过有界解析和参数化SQL，不直接执行表达式。

搜索键使用版本化textkey/v1的Unicode NFKC、大小写折叠与自然数字排序，不就地改变已使用的规范化语义。

查询最多1024个Unicode字符／4096字节、256个节点、16层嵌套。语法错误返回字符位置，不把非法条件当作空搜索。标签基于原始namespace/name，译名用于展示与建议，不改写原始身份。属性过滤、人工值和多语言规则见[属性契约](properties-tag-suggestions.md)。

scope表示all／favorites／missing_metadata／missing／corrupt／hidden等业务范围，与界面的library_scope=all无关。当前书库未解析时不查询业务列表；停用库、显式跨库、旧library参数及保存搜索的库归属遵循[当前书库契约](current-library-context.md)。不能借后端空library_id语义把单库意图扩大为全部。

## 匹配、折叠与分页

先匹配物理Edition，再按none／works／series折叠，保留匹配成员；旧versions折叠仅作为输入兼容别名。普通搜索默认series折叠、索引时间降序、每页24项，上限100；管理查询显式处理visibility、停用与元数据状态，强制物理明细而不是套用普通折叠。

计数和页内结果在同一读快照完成，不能先分页再折叠。代表从允许的书库／范围／隐藏条件内选择，Work优先其可用首选，否则采用稳定替代；Series按位置选择允许成员。代表未命中时保留其他成员命中信息，不改写真实首选版本。

排序使用匹配成员的规则和稳定ID消歧，标题用允许成员自然标题键，索引时间使用相应聚合值。标题变化不自动重排Series的人工顺序。完整命中明细分页读取，不能把有界内联ID当作全部成员。

影响结果的目录、来源、人工值、组织或账号状态提交推进查询版本；任务心跳和秘密设置不使查询过期。跨页和命中明细校验snapshot_revision，过期返回409 search_snapshot_expired；网页保留明确筛选和草稿，重新读取有效分页，不维持跨HTTP请求的长期数据库事务。

## 收藏、隐藏与保存搜索

收藏／隐藏属于账号与Edition，有独立revision；重扫、元数据更新和组织变换不覆盖它们。分组折叠不是隐藏，普通范围排除隐藏，hidden范围明确查询隐藏成员。明确的全Work收藏必须核对各Edition账号状态版本，不能借组织revision代替；不隐式整组隐藏。

保存搜索归账号所有，查询格式版本为1，只保存已应用条件，不保存页码、snapshot或结果ID。加载时重新查第一页，并按当前书库规则解释旧库条件；库不存在报错，不偷偷扩大范围。保存、改名、更新和删除使用对应revision，不能静默覆盖并发修改。

客户端 Work 查询支持单库折叠、继续阅读范围和最近阅读时间排序，独立保留首选、命中和继续版本。当前阅读状态及查询契约见[客户端协议](client-foundation.md)。正则及面向用户的向量检索仍待开发。
