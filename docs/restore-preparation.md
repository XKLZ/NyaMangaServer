# 恢复准备

恢复前不需要清空已有实例。应用会校验备份、预览目录映射，并保护目标以便受控回退；不要手工删除数据库来绕过错误。

- 保存备份包及对应版本、完整构建身份的程序或镜像。
- 明确目标配置、允许根、秘密写入位置及磁盘空间。
- 同时保存源漫画；应用备份不包含漫画本体。
- 核对后台任务和维护状态，停止服务后才能使用离线恢复命令。
- 先预览，确认后使用同一请求准备，再正常重启激活。
- Docker 根映射使用容器内路径；只读挂载、相对文件名和文件大小需匹配。

具体命令与失败保护见[备份与恢复](backup-restore.md)及[Docker 部署](../deploy/README.md)。

早期私人测试清理与真实恢复记录不进入首次公开源码；它们不授权清理用户实例。
