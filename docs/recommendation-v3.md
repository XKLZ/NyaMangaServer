## 可复现命令

从仓库根目录运行，仅首次生成允许写新包；已有候选包拒绝覆盖：

```sh
PYTHONDONTWRITEBYTECODE=1 .runtime/cache/recommendations/venv/bin/python experiments/recommendations/study.py prepare-v3
```

准备使用原run-v2完整导出和三个固定特征索引，逐封面核对实际字节与缓存身份；不生成新的特征或改写V2输入。历史关键文件及分析目录SHA256在准备前后核对，批准的V2策略摘要仍为`45e27a79a7d945e7d830d6b557156b5b914a550e0a6066ed1e5f9025d15caeb9`，评分源码及冻结输入保持一致。旧score/evaluate命令仍拒绝新四类包。

用户标注完成后，由主Agent显式执行校验；此命令不是质量评估：

```sh
PYTHONDONTWRITEBYTECODE=1 .runtime/cache/recommendations/venv/bin/python experiments/recommendations/study.py validate-labels --output .runtime/tests/runs/recommendations/run-v3 --labels .runtime/tests/runs/recommendations/run-v3/labels.user.v3.json
```

私人候选、封面、书籍ID、特征及逐项结果仅在被忽略的.runtime目录，目录0700、生成文件0600。最终发布candidates.json之前完成输出、历史摘要检查及隔离检查，重复执行不能覆盖已发布候选或用户标注。

## 标注后的V3工作约定

用户确认标注完成后再启动一个实验Agent。主Agent保管新120对答案，Agent在冻结前只获准读取开发数据；共享目录不构成访问授权，必须在派发指令和评估闸门中明确隔离。

| 子系统 | 改进方向 |
|---|---|
| 同作品 | SSCD作为主信号，取消标题相似度一刀切；标题、卷篇序号、页数和创作者用于补充证据与风险，重点防止把不同卷当作同作品 |
| 同系列 | 分离主体、副标题、版本修饰和带类型／歧义的序号；比较原题与清理后题名语义，降低署名和版本修饰干扰 |
| 特征 | 原题向量保留；仅文本变化时使用同一MiniLM补算清理视图，独立版本缓存，不改V2摘要 |
| 冲突 | 区分缺失与明确不一致，解释合集／单篇、页数悬殊和序号冲突；证据竞争进入待复核，不连锁扩组 |
| 排序 | 多路召回去重并重新排序，报告最终总top5／10／20及候选数量，不能只报告每路线topK并集 |
| 输出 | 同作品／同系列关系、较强建议／待复核层级、依据、风险及算法版本；分数不称为概率，不把人工不确定标签输入预测 |

开发前预先记录有限候选策略、参数范围与选择规则。用300对比较V3、固定V2及SSCD单信号，不预设融合更好。目标为建议精确率至少95%，每种建议至少10条的非退化条件下提高召回；达不到如实报告。

冻结源码、参数、输入摘要、指标政策并经主Agent审查后才释放120对答案，评估一次、不返调。报告TP／FP／FN、精确率、召回率、区间、各层质量、复核比例和最终候选数量；uncertain与部分重叠单列，正例转复核仍计入主召回遗漏。本轮只验证书籍对及候选排序，加入已有组的组级一致性留待整合前验收。

继续沿用SSCD／MiniLM和精确依赖，离线CPU单线程、缓存复用；仅执行相关解析、风险、缓存、排序、冻结闸门和报告测试。记录Mac开销，N5105 NAS性能仍未实测。本轮不接入应用或推荐流程，不自动推进其他阶段。
