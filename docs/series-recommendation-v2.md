# 系列推荐离线V2：受约束聚类

基于`3928933`，在`codex/series-recommendation-v2`串行实施。仅独立实验与文档，不修改正式应用、业务库、API或运行服务；不联网、不加载模型、不部署、不推送。V1及历史输入、标注、源码和缓存保持不变。

## 固定协议

保留V1的Work画像、两两评分、召回路线及已冻结门槛，不重新选参。完全连接与受约束平均连接各比较旧共同主体、新代表题名画像，共四项对照。平均连接要求跨组均分达到既有补充门槛、最低配对分≥0.40，并拒绝明确题名主体冲突；完全连接要求全部跨组关系通过原补充规则。所有跨组关系实际检查，召回缺边不等于通过。组上限1000，稳定ID打破平局，不预设组数、不强制孤立Work入组。

新画像以组内总相似支持最高的Work为代表，保留该Work各Edition原题/有效题名作为明确别名；每个成员直接检查代表的题名支持，不沿别名链扩展。现有主体冲突线0.35固定沿用，不新增搜索。未知括号和固有数字不额外删除。较强组须完整满足强层条件，风险不得被均分掩盖。

主方案为不重叠分区。歧义固定定义为：成员能加入另一个最终组，加入层级相同、对成员的平均支持与本组差值≤0.05（沿用旧网格最小步长），不通过人工答案决定。单次快照同时移出歧义成员，避免迭代顺序影响；备选在移出后重验，每成员最多3项。已确认Series为不可拆合锚点，其原成员不进入歧义移除；本轮只用匿名及直接人工正关系构造的虚拟场景，不读业务库。

420条均为已见开发数据。复用V1五折隔离和各折仅由另四折确定的评分门槛；本轮不选聚类参数。分别报告四项对照、歧义移除前后、全数据拟合与OOF结果，未知不当负例、人工答案不作为聚类约束。V1完整方案65/132仅与相同全数据策略口径比较，不与OOF混算。没有完整组真值，不能声称整组精确率95%。

输出限定`.runtime/tests/runs/recommendations/series-v2/`，目录0700、文件0600，取消不发布半产物，完成后verify只校验。单线程、2GiB软预算、模型加载/推理0，Mac资源记录不代表NAS实测。

三个增量已完成。26项独立定向匿名检查通过，覆盖链式误组、召回缺边、稳定排序、容量、锚点、缺题名、多版本题名、歧义、三备选上限、取消原子发布、manifest、输出边界、页面脚本安全、所有对照/视图及列表和成员分页。只做JS语法和匿名DOM检查，未做浏览器视觉验收或应用构建，不沿用历史部署结果。

主方法9条已知误配分布于5个方案；385/407个方案仍含未标注关系。不能把它们算成正确或错误，也不能声称整组准确率92.37%。23条未同组的正例中：7条分属不同主方案、12条一端或两端未分组、4条涉及待核对成员。仅考虑已输出前三项备选，主方案或备选可触及110/132；这是可能去向覆盖，非已经成组的召回。歧义移出减少2个误配，同时损失2个正例；完整组指标与复核代价均保留，不只报告去重。

实验Work仅由既有明确同作品关系构造（101个多版本Work），其余为单版本，不能视为用户当前已经完整整理的真实业务Work。未知的版本关系可能影响系列方案，不能从本实验反推真实全库分组已经正确。

## 五折开发检查与限制

不再搜索参数，沿用V1每折由另四折选择的门槛。聚类使用完整池的无标注特征作为传导式上下文，分别按原验证折计分；不把全数据拟合门槛冒充OOF。由于全部样本都已见，且没有完整组真值，这仍是开发检查，不是新留出或全库Series质量验收。

| 主方法层级 | TP / FP / FN | 配对精确率 | 配对召回率 |
|---|---|---:|---:|
| 五折较强 | 54 / 6 / 78 | **90.00%** | 40.91% |
| 五折合计 | 109 / 9 / 23 | **92.37%** | **82.58%** |
| 全数据较强（仅复核策略） | 51 / 2 / 81 | 96.23% | 38.64% |

五折合计P的Wilson95%区间为86.14%–95.94%，R为75.21%–88.10%；较强层**未达95%目标**，不能用全数据较强96.23%代替五折90%。其余对照的完整指标/区间保存在私有report。2个直接人工正关系构造的虚拟加入场景均生成方案；匿名测试另覆盖多个锚点竞争、固定原成员、非首选题名和既有顺序保护，不代表真实已整理系列验收。

**暂不直接接入应用。** 组合爆炸已消除、覆盖有改善，但仍需人工核对完整方案，特别是5个含已知误配的组、最大39成员组及顺序不确定的组。不根据当前结果改阈值、扩大策略或将未知关系补成真值。
