# 全局当前书库：范围与前端交接

2026-10-26，用户已批准实施。共享当前书库、业务页接线、切换保护及匿名验证已在下述四个增量中完成；执行契约和后端只读核对继续保留，实际结果及未验证范围见末节。

## 基线与分工

前端执行需读取refactoring-ui与web-design-guidelines，沿用React／Ant Design、明暗主题及紧凑导航，不新增大标题、常驻解释区域或重复选择器。

## 已核对的后端边界

目前空筛选真实表示全部，并不是自动选择了某个书库。网页选择框空白而请求不带library_id，因而得到包含停用库的全部作品／系列，造成范围不一致。

| 能力 | 当前接口与语义 |
|---|---|
| 书库目录 | GET /libraries，按display_name、id返回；客户端排除disabled／trashed_at后确定默认项，不能按源目录在线状态过滤 |
| 漫画／元数据管理 | POST /admin/books/search，library_id在SQL分页前筛选；include_disabled默认false，即使明确指定停用库仍需true才能显示其漫画 |
| 作品／版本列表 | GET /works?library_id=…&min_editions=2；查询总数和分页同读事务；不指定库允许全局 |
| 系列列表 | GET /series?library_id=…；同快照计数分页；不指定库允许全局 |
| 方案列表 | GET /work-proposals、/series-proposals，均支持library_id，SQL筛选先于分页 |
| 任务列表 | GET /jobs?library_id=…，不仅检查jobs.library_id，也检查job_items所属Edition，能包含本库的元数据／查询任务；不能因为job.library_id为空就擅自当作全局 |
| 导入历史 | GET /import-batches?library_id=…，服务端同快照筛选、计数、分页 |
| 明确归属 | Edition／Work／Series、系列方案、导入批次详情可获得所属库；同作品方案没有直接library_id，可先读关联任务，其次读现存目标Work／成员Edition确认，均失败时阻止业务列表与提交并提示无法确认，不能猜库 |
| 任务深链接 | 优先任务明确library_id；GET /jobs/{id}/import-batch可解析普通导入任务和metadata_search的批次，再读批次。真正跨库／全局任务不猜测归属、不重写成员 |
| 维护及全局设置 | 本轮保持全局，不进行前端分页后按库过滤，也不假造缺失的维护筛选接口 |

这些是源码核对，不代表已运行本轮匿名浏览器流程。保留现有API空参数兼容语义；不增加新的后端“默认当前库”。前端所有单库请求在上下文有效后显式带库，不在网页拿到一页后再过滤。只在解析一个深链接时允许必要归属读取，不能为每个列表项增加详情请求。

## 唯一选择器及解析顺序

管理台顶部唯一当前书库选择器，桌面紧凑、手机可访问；移除业务页重复选库。

优先级：详情对象实际归属 → URL明确库 → 当前标签页已有库 → 本账号上次启用库 → /libraries中首个启用且未回收库。源文件离线不影响浏览资格。按account_id保存上次启用库的本地界面偏好，不保存凭据，不新增服务端设置。各标签页独立，不响应storage事件自动切库；普通导航／刷新保留当前选择。显式停用库通过URL保留，不作为新会话自动默认项。

解析前业务列表不请求，不先展示全局再切库。没有书库显示添加入口；全停用／回收显示暂无启用书库，提供管理及显式查看停用库。记忆库失效回退首个启用库并短暂提示；URL明确不存在则显示失效状态，不改为全部。目录列表加载失败保留已加载内容，阻止未确定范围的新操作并提供重试。当前库后来停用时保留查看与停用标记，不突然跳库；回收后停止普通业务查询，提供恢复／换库入口。

普通列表只含启用未回收库，高级“查看停用书库”显式进入，顶部持续标记已停用。停用库查看漫画须派生include_disabled=true，仅限明确指定的库；不因为看停用库就移除library_id或扩大范围。维护限制沿用后端，不自动启用、恢复任务、读取源文件或运行发现。回收库从维护中心处理。

## 页面范围、URL与保存搜索

| 页面 | 范围 |
|---|---|
| 漫画／元数据 | 默认当前库，高级入口显式跨库查看 |
| 版本／系列 | 必须明确单库，不支持全库模式 |
| 任务／导入历史 | 默认当前库，明确的当前／全部切换 |
| 导入批次详情 | 固定批次所属库 |
| 书库管理 | 全部书库；顶部当前库不筛掉其他行 |
| 维护中心 | 全局回收站／存储／清理，明确全局标记 |
| 站点／译库／账号安全 | 全局设置；切库不改变设置范围 |

library_scope=all是页面显式跨库模式，不复用现有搜索scope（all／favorites等）字段。全局仍保留最后单库；离开跨库汇总到版本／系列回到该库。漫画跨库默认排除停用库，保留显式包含停用选项；任务／历史全库包含停用库历史。跨库页面明显标全部书库。

新链接统一library_id，兼容旧library。两参数非空且不同则冲突不猜；相同规范为一个。旧空参数是未指定，不能据此隐式查全库。空白和无效参数的规范化使用共享解析函数，不让各页决定。

已有保存搜索含库ID则进入该库；空库记录进入显式全库查看，不改旧记录。保存库不存在报错，不扩大范围；指向停用库按显式查看规则处理。保存仍用原版本1条件格式，存实际条件和范围，不存全局偏好、页码或snapshot；不把新增UI的library_scope误写入服务端不认识的条件字段。空library_id仍是服务端格式1的跨库表示；它只在加载保存搜索和用户显式跨库时转换成页面library_scope=all。

详情对象与URL库冲突时，以核实的对象归属规范链接并短暂提示，未核实前禁止提交及其他库配套列表。草稿离开保护不能因自动规范化被绕过。任务身份不随选择器改写，未知或跨库任务不猜归属。

## 统一切换与数据保护

所有入口共用切库流程。写入中暂禁切换，表单／成员／关系草稿走现有统一离开保护；取消时选择器、URL、上下文、偏好不变。成功后保留页面类别、通用已应用筛选和排序，页码回1；清原库批量选择、详情、方案、成员页、撤销提示和snapshot。详情切库回新库历史／任务列表，不改原对象归属。

终止旧列表读取，以书库和请求身份隔离晚到响应，不把旧库内容当作新库加载结果。持久任务不因网页切库暂停／取消。SSE不切库、不覆盖草稿、不提升冻结提交版本。书库目录真实状态变动按上述失效规则展示，不偷偷换库。

## 前端增量一：共享解析与选择器

已新增共享范围解析、账号／标签页偏好、对象归属读取及顶部选择器组件；组件先独立验证，业务页接线在下一增量完成。解析定向7项通过，覆盖启用／停用／回收／离线、优先级、失效与冲突URL、显式跨库、切换清理及账号隔离。前端类型与ESLint通过。此增量尚不代表完整页面验收；未改后端、运行配置或真实数据。

## 前端增量二：四类业务页接线

顶部当前库及解析门控接入管理台，漫画／元数据请求明确派生library_id；停用单库同时派生include_disabled=true。版本／系列从共享上下文读取库，移除原重复选择器，旧library_id→library反向写回已移除。漫画显式跨库入口在更多筛选内，现有scope查询语法不变。跨库切换或单库变化用范围身份重建页面状态，统一导航保护开始覆盖library_id／library_scope及系列对象变化。书库管理和设置仍为全局数据范围。

本增量前端类型、ESLint及95项单元通过，更新后的解析定向7项再通过；尚待任务／历史／保存搜索、写入锁和匿名浏览器综合验证，不能据此宣称全流程完成。

## 前端增量三：历史、深链与保存搜索

任务及导入历史复用共享书库，移除重复选库并提供明确的当前／全部切换；批次与Edition／Work／Series／方案归属在配套列表之前核实。没有直接library_id的任务尝试关联批次；真正全局任务保持任务ID，不猜成员归属。同作品方案按任务、现存目标作品、成员Edition核实，404可尝试下一依据，无法确认则阻止。保存搜索明确库按URL进入，旧空库显式转为library_scope=all；提交保存条件剥离UI范围、偏好、页码和snapshot，仍为格式1。新生成的查找任务链接使用library_id。

97项单元通过；移除归属核对实现中不再使用的类型导入后，类型及ESLint通过。综合匿名浏览器、目录状态变化和写入锁仍属下一增量，不沿用旧轮截图为本轮证据。

## 前端增量四：切换保护与交付

共享导航保护覆盖库切换、批次、漫画、系列和版本对象；提交期间选择器和范围入口锁定，离开页面也不能绕过进行中的写入。放弃前的取消保留URL、选择器和账号偏好，接受切换后重建业务范围，清除旧库选择、分页、详情及snapshot。搜索POST仍视为读取；并行写入全部结束或失败／取消后才解除锁定。

书库目录失败保留同范围已加载内容，顶部固定重试入口替代高级按钮；无可确认范围时不挂载业务列表。当前库后来停用继续浏览，回收则暂停业务GET并隐藏相关弹窗，恢复后保留挂载草稿与起始版本。全局页面不因首次目录解析重新挂载表单。归属核实过程中保留底层列表高度，跨库漫画列表打开详情保留跨库条件、勾选、滚动和最后单库记忆；批次／任务则继续按实际归属收敛范围。
